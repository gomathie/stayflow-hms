# Security Policy

Salisberg values the contributions of the security research community, and we look forward to working with you to minimize risk to QloApps users.


## Reporting a Security Issue

If you have found a security issue in QloApps, please do not use the issue tracker and don't publish it publicly. Instead, report the security issue to gochairman2@gmail.com. So that we can act on it immediately to avoid as much damage as we can.
